Запуск:

1) Поднять сервисы:
   docker compose up -d

2) Запустить тесты:
   GOFLAGS="-tags=integration" go test ./tests/integration -v

Переменные окружения:
- INTEGRATION_BASE_URL (по умолчанию http://localhost:8080)

Тесты покрывают:
- поиск рейсов
- создание бронирования
- получение бронирования
- отмену бронирования
- список бронирований
- невалидный payload
- бронирование с нехваткой мест
- повторная отмена
- отсутствие бронирования
- пустой список для пользователя
